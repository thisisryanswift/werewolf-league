# League comparison view (absolute metrics across Leagues)

## Parent
Spec wl-xgp7 (Spec: Werewolf League on Durable Objects). Vocabulary: GLOSSARY.md. Architecture: docs/adr/0001, docs/adr/0002, docs/adr/0003.

## What to build
A panel comparing Leagues and Agents on metrics that don't depend on the pool (unlike Elo):
- **Calibration** (Brier, village ballots);
- **reliability:** timeout rate per turn, illegal-call rate per turn;
- **turn latency** p50/p90;
- **cost** per Match and per turn (from wl-64dn).
Rows per Agent with its League and Harness (e.g. 'Hydrogen · Managed' vs 'Hydrogen · Pi'), plus a League-level summary.

**Instrumentation gaps to close:** the smoke test found illegal or out-of-phase calls aren't counted (the Player DO retries silently). Record an invalid_call count per turn, and each turn's duration, in the turn result. Both feed this view.

Explain in the panel that Elo is per League and not comparable across Leagues.

## Acceptance Criteria

- [ ] Fake-Harness tests: invalid calls and turn durations are recorded and aggregate per Agent and per League
- [ ] The panel shows the metrics above for both Leagues side by side, and says Elo isn't comparable across Leagues
- [ ] Values update as Matches settle
